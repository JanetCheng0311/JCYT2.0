# JCYT — Portfolio

Personal portfolio of **Janet Cheng (Cheng Yu Tung)** — a Hong Kong multimedia
designer working across graphic design, motion, 3D and creative coding.

**Live:** https://janetcheng0311.github.io/JCYT2.0/

The site's signature is a generative **ASCII flow-field** rendered as flowing
numbers (inspired by classic p5.js flow-field sketches), used as a living
background across the site.

## Pages
- **Home** — the animated number-field hero
- **Work** — projects grouped by year on a scroll-following year ruler; each
  project opens its own page with a full image gallery
- **About** — background, education, experience, skills and awards
- **Contact** — email, GitHub and Instagram

## Editing
All page content lives in plain-text files under [`content/`](content/) and the
project images under [`assets/work/`](assets/work/) — no code editing needed.
Step-by-step guides (English + 繁體中文) are in `HOW-TO-EDIT (*).txt`.

## Tech
Static HTML / CSS / vanilla JavaScript (HTML5 Canvas for the background),
self-hosted Geist fonts, hosted on GitHub Pages. No build step.
