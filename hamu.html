Hamster Autumn Meadow Uproll

YouTube ↗

Overview

HAMU (Hamster Autumn Meadow Uproll) is a cozy game prototype built in Unreal Engine, centred on collection gameplay set in a procedurally built environment.

Mascot

Gameplay & mechanics

The prototype centres on collection gameplay. The environment is assembled using Unreal's PCG (procedural content generation) tools, and the core gameplay systems are built in Blueprint.

Process

  • Collection gameplay design
  • Environment building with PCG
  • Gameplay systems in Blueprint
  • AI-assisted visual development

Tools

Unreal Engine PCG Blueprint

Outcome

A playable prototype, captured in a gameplay video.
