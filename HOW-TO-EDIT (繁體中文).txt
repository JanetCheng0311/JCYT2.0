============================================================
 JCYT 作品集 — 如何修改你的網站
 （簡單教學 — 不需要寫程式）
============================================================

基本概念
--------
你整個網站的文字和圖片，都是從「content」資料夾裡幾個純文字檔讀出來的。
你只要改文字檔，再按一個按鈕發佈就完成了。

  - 你的網站網址：
      https://janetcheng0311.github.io/JCYT2.0/
  - 所有可以修改的檔案都在這個資料夾：
      /Users/janet/Downloads/portfolio/

你只需要在兩個地方改東西：
  1. content/about.txt   → About（關於我）頁
  2. content/work.txt    → Work（作品）頁
  3. assets/work/         → 你的作品圖片都放這裡


三個按鈕（雙擊使用）
--------------------
  1-Edit-content.command       用 TextEdit 打開你的文字檔。
  2-Preview-locally.command    只在「這台電腦」預覽網站，
                               讓你發佈前先檢查。
                               （關掉那個黑色視窗就會停止。）
  3-Publish-to-website.command 把你的修改放上網。需要網路 + 你的
                               GitHub 登入。大約 1 分鐘後生效。

第一次使用：雙擊 .command 時，Mac 可能會問「你確定嗎？」，
按「打開 / Open」就可以。之後就會直接執行。


平常的步驟
----------
  1. 雙擊  1-Edit-content   → 改文字 → 儲存（Cmd+S）。
  2. （可選）雙擊  2-Preview-locally  → 檢查是否正確。
  3. 雙擊  3-Publish-to-website  → 完成。等約 1 分鐘，然後重新整理
     你的網站（按住 Shift 再點重新整理）。


讓檔案能正常運作的規則
----------------------
  - 以  #  開頭的行是「備註」，網站會自動忽略。
  - [方括號] 裡的「區段名稱」要保持原樣，不要改。
  - 欄位之間的直線  |  要保留，就算某欄是空的也要留著。
  - 看到的引號、逗號要保持原樣。
  - 不確定的時候，複製一行現有的，再改裡面的字就好。


------------------------------------------------------------
 修改 ABOUT（關於我）頁  content/about.txt
------------------------------------------------------------
檔案最上面（每項一個值）：
  NAME      = 頁面上「大字」的名字        （例：Janet）
  FULLNAME  = 下面「小字」的全名          （例：Cheng Yu Tung）
  ROLE      = 你的一句話職稱
  LOCATION  = 你的所在地

[INTRO]
  這裡每一行會變成一個段落。

[EDUCATION]      格式：   - 課程 | 學校 | 日期
  每個「- 」開頭的行是一筆。不需要的欄位可以留空，
  但要保留 | 直線，例如：   - IELTS 7.5 | |

[EXPERIENCE]     格式：   - 職位 | 機構 | 日期 | 你做了什麼

[TOOLS]          你會用的軟體，用逗號分開。
[LANGUAGES]      你的語言，用逗號分開。

[AWARDS]         格式：   - 標題 | 年份 | 備註 | 連結
  沒有連結就把連結留空。如果加上連結，會出現一個小小的「View」
  按鈕，讓人點開那個獎項的頁面。

新增一筆：複製一行「- 」開頭的，貼在下面，改字。
刪除一筆：把那一行「- 」整行刪掉。


------------------------------------------------------------
 修改 WORK（作品）頁  content/work.txt
------------------------------------------------------------
每個作品是「一個區塊」，由  [PROJECT]  開頭，包含：

  ID       = 網址用的短名稱（只用英文字母和「-」），
             例：grafri  →  作品頁網址變成  project.html?p=grafri
  TITLE    = 作品名稱（中文或英文都可以）
  YEAR     = 年份數字，例：2024
             （側邊的「年份尺 / RULER」就是看這個，頁面也會自動
              由新到舊排序）
  CATEGORY = 簡短標籤，例：Poster design
  DESC     = 一句簡短描述
  LINK     = 可選的連結（沒有就留空）
  COVER    = 在作品「列表」上顯示的那張圖。
             留空的話，會自動用 IMAGES 的第一張。
  IMAGES   = 這個作品的所有圖片，用逗號分開。

新增作品：複製一整個 [PROJECT] 區塊（由 [PROJECT] 到它的 IMAGES 行），
  貼上，改字，並給它一個新的 ID。
刪除作品：把整個 [PROJECT] 區塊刪掉。


------------------------------------------------------------
 幫作品加圖片
------------------------------------------------------------
  1. 把圖片檔放進這個資料夾：
        assets/work/
     （也可以每個作品開一個子資料夾，例如
        assets/work/chiikawa/ ）

  2. 在 content/work.txt 的 IMAGES 行寫上檔名，用逗號分開。
     不用寫「assets/work/」，只要寫檔名就好。例如：

        IMAGES = hkfaa-eternal-moment.jpg
        IMAGES = chiikawa.jpg, chiikawa/detail-1.jpg, chiikawa/detail-2.jpg

  3. （可選）用 COVER 指定列表上顯示哪一張：
        COVER = chiikawa/detail-1.jpg

  4. 發佈（按鈕 3）。

小提示
  - 在 Work 頁點一個作品，會打開它「自己的頁面」，把 IMAGES 裡的
    每一張圖都按原本比例顯示出來。
  - 圖片存成寬約 1200-1600px 最理想。檔案太大網頁會變慢。
  - 支援格式：.jpg  .jpeg  .png


------------------------------------------------------------
 如果看起來怪怪的
------------------------------------------------------------
  - 看不到剛改的東西？按住 SHIFT 再點瀏覽器的重新整理
    （這會清掉舊的快取版本）。
  - 圖片是空白／破圖？檢查 work.txt 裡的檔名跟 assets/work/ 裡的
    真實檔名是否「完全一樣」（大小寫、還有 .jpg / .png 結尾都要一樣）。
  - 發佈失敗？檢查網路，然後再雙擊一次按鈕 3。
  - 發佈前隨時可以用「按鈕 2」在本機預覽。

就這樣。改文字 → 預覽 → 發佈。祝你玩得開心！
