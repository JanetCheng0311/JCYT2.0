# ============================================================
#  JCYT — WORK / PROJECTS
#  Edit the projects below, then double-click "3-Publish-to-website.command".
#
#  HOW IT WORKS
#  - Each project is one [PROJECT] block.
#  - Clicking a project on the Work page opens its own PROJECT PAGE,
#    which shows every image listed in IMAGES (at its real size).
#  - To ADD a project: copy a whole [PROJECT] block and change the words.
#  - To REMOVE a project: delete its whole [PROJECT] block.
#
#  FIELDS
#  ID       = short name used in the web address (letters/numbers/dashes)
#  TITLE    = the project name
#  YEAR     = a year number (drives the year ruler + sorting)
#  CATEGORY = a short label, e.g. Poster design
#  DESC     = one short sentence about it
#  LINK     = an optional web link (leave empty if none)
#  LINKS    = one or more buttons. Format:  Label|url, Label|url
#             e.g.  LINKS = Behance|https://..., Picrew|https://...
#  COVER    = the image shown in the Work list (leave empty = first IMAGE)
#  IMAGES   = all the project's images, comma-separated. They live in
#             assets/work/  (each project has its own sub-folder).
#
#  >>> Lines marked  "# CHECK"  are projects whose title/year I'm unsure of.
#      Please fix them, then publish.
# ============================================================
