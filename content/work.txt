#  - Each project is one [PROJECT] block.

#  - To REMOVE a project: delete its whole [PROJECT] block.
#  - The page sorts projects by YEAR automatically (newest first) and the
#    year ruler on the side follows your scroll.
#
#  FIELDS
#  TITLE    = the project name
#  YEAR     = a year number, e.g. 2024  (drives the year ruler + sorting)
#  CATEGORY = a short label, e.g. Poster design
#  DESC     = one short sentence about it
#  LINK     = an optional web link (leave empty if none)
#  COVER    = optional small thumbnail (leave empty to show a letter tile)
#  IMAGES   = the gallery images, comma-separated. All images live in
#             assets/work/  — just write their file names here.
#
